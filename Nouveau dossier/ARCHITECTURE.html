🔍 Scrapers (Collecte de Données)

🏠
CROUS Scraper
Scrape les logements étudiants sur trouverunlogement.lescrous.fr avec filtrage par prix et zone Toulouse.
crous_scraper.py
🎓
PhD Scraper
Collecte les offres de thèses depuis ABG, theses.fr, ADUM et les sites des labos toulousains (IRIT, LAAS, TéSA).
phd_scraper.py
💼
Internship Scraper
Recherche les stages M2/Ingénieur sur Indeed, HelloWork et les portails universitaires.
internship_scraper.py

💾 Gestion des Données

🗄️
Database Manager
Base SQLite avec tables pour logements, thèses et stages. Gère la déduplication, l'historique et les statistiques.
database.py
🔄
Main Orchestrator
Coordonne tous les scrapers, gère les erreurs, les logs et l'envoi des notifications.
main.py

📧 Système de Notifications

✉️
Email Notifier
Génère et envoie des emails HTML premium avec design futuriste. Statistiques visuelles et liens directs.
email_notifier.py

🎨 Interface Utilisateur

📊
React Dashboard
Interface web "Research Command Center" avec statistiques en temps réel, navigation par onglets et design ultra-stylé.
frontend/index.html

⚙️ Automatisation

🤖
GitHub Actions
Workflow automatisé qui s'exécute quotidiennement, commit les résultats et nettoie les anciennes données chaque semaine.
.github/workflows/daily-scrape.yml

✨ Fonctionnalités Clés

🎯
Filtrage Intelligent
Focus automatique sur image, vidéo, signal, télécommunications et domaines connexes.
🚫
Déduplication
Détection et suppression automatique des offres en double via hash intelligent.
📈
Statistiques
Tracking complet avec historique, nombre d'offres, durée des scraping et taux de réussite.
🔔
Notifications Ciblées
Email uniquement pour les nouvelles offres, pas de spam avec les anciennes.
🧹
Auto-Nettoyage
Suppression automatique des offres de plus de 90 jours pour garder la base propre.
⚡
Performance
Cache intelligent, rate limiting et gestion d'erreurs pour un scraping rapide et fiable.
